# LED在各芯片上的特性对比

|**特性**|**110**|**173**|104|
|---|---|---|---|
|共阴 or 共阳|共阴|||
|工作模式|- 10SEG  \* 8COM矩阵模式||- 11SEG x 9COM矩阵模式<br>- 8 x 9串行点阵模式|
|工作时钟|PCLK/4 \~ PCLK/256可配置||PCLK / \(PSC\[9:0\]\+1\)|
|亮度调节|可选择的亮度调节：12\.5% \~ 100%可调节，步进12\.5%<br>||- 矩阵模式：可选择的亮度调节<br>- 点阵模式：不支持可选择的亮度调节|
|闪烁控制|支持||- 矩阵模式：支持<br>- 点阵模式：不支持|
|驱动能力|GPIO模块控制||- GPIO模块控制<br>- LED 模块控制|

*注：*

*1、102/103/171不支持**LED*
