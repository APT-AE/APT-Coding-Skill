# APT32F004x系列产品说明（对外密）

# 研发目的

102的基础上降低成本

- 删除touch

- 裁剪部分IP功能

- 20pin产品

# Die内模块构成

CK801内核。

# 使用注意事项

- 有两组SWD，0041和0042不同封装默认SWD口不一样。

- 有SWD lock功能，如果要将SWD口改为其他AF，需要先解锁。

- 当前驱动版本不支持UART校验。如果客户有需求，可以定制。

- 使用SYSCON 输出触发CH4或CH5(TRGOUT4/5)时，PCLK只能选择1分频。

- 不支持SLEEP MODE
