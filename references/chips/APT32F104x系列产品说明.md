# APT32F104x系列产品说明（对外密）

# 研发目的

- 支持点阵LED（之前102用软件实现时驱动亮度欠佳）

- touch不使用C0

- 系列内存在型号 pin2pin兼容 CMS80F7318、BF7612、738、0701

- 28pin 产品

# die内模块构成

CK801内核。

# 使用注意事项

- 有SWD lock功能，如果要将SWD口改为其他AF，需要先解锁。

- 当前驱动版本不支持UART校验。如果客户有需求，可以定制。（\~2024\.12\.20）

- 当前驱动版本不支持LED点阵3\*4，5\*6，7\*8，如客户有需要，可以定制。（\~2024\.12\.20）

- 使用SYSCON 输出触发CH4或CH5(TRGOUT4/5)时，PCLK只能选择1分频。

- GPTB 选择SYNINC4（EXTCLK）时，CNT可以计数，但是PWM不能输出。

# 关键模块快速索引

## 数据类型：`Driver/inc/types_local.h`
无符号 `U8_T/U16_T/U32_T`，有符号 `S8_T/S16_T/S32_T`，浮点 `F32_T/F64_T`，布尔 `B_T`。
命名前缀：`by`=U8，`hw`=U16，`w`=U32。

## 初始化流程：`initial.c` 的 `apt32f104_init()`
syscon 开时钟/振荡器 → 设中断优先级 → 开全局中断 → console_init → 各外设 config → tk_config(必须最后)

## 中断：`interrupt.c` + `top.h`
CK801 VIC，ISR 用 `__attribute__((isr))`，函数名固定(CORETHandler/BT1IntHandler/TKEYIntHandler/ADCIntHandler…)。
中断号见 `top.h`：CORET_INT=0, TKEY_INT=25, BT1_INT=29。
清标志方式：读 MISR 判位 → 写 ICR 清。

## 触摸(TKEY)：`tkey_lib.h`（闭源库 `lib_apt32f104_tkey_*.a`）
API：`tkey_sram_clr` → `tk_Variable_initial` → `tkey_parameter_init` → `tkey_init`(初始化)；
`tk_main_scan`(主循环)；`tkey_basecnt_process`(放 CORET 中断)；`tkey_int_process`(放 TKEY 中断)。
输出：`wSamplingData`/`wBaselineData`/`nOffsetData`/`wKeyMap`
通道 TCH0~25(26路)，AF=11；TCH12/13(PA02/03)复用SWD，配置前须 `syscon_swd_unlock()`。
