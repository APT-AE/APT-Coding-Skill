# APT 驱动库分代

APT 驱动库存在代际差异，**不是所有芯片的 API 都相同**。

## 分界

| 代际 | 芯片 | 说明 |
|------|------|------|
| **新驱动** | 004, 104, 170, 031, 005 | 从 004 起使用新驱动代码 |

> 004 之前没有旧驱动芯片，所有现有芯片均为新驱动。

## 迁移影响

- **Case 1(跨厂)**：无影响，本来就要写适配层，直接用新驱动 API。
- **Case 2(同厂升级)**：**芯片同在新驱动代，API 基本兼容**，仅在具体外设/引脚/主频有差异。
- **Case 3(从零)**：直接用新驱动。
