# 关于32\.768Khz外部辅振配置优化说明



## 简介

本历程基于32F110x系列芯片说明如何进行32\.768Khz外部辅振配置优化，亦同样适用于32f102x系列。在RTC模块的使用时，选择ESOSC 32\.768Khz晶振时，参数配置不当时，等待时钟源稳定的耗时需要3秒以上。

```C++
csi_error_t csi_esosc_enable(uint32_t wFreq)
{    
        if ((csi_pin_get_mux(SXIN_PIN) != SXIN_PIN_FUNC) || (csi_pin_get_mux(SXOUT_PIN) != SXOUT_PIN_FUNC))
                return CSI_ERROR;     
        csp_set_es_gain(SYSCON, 0x7);
        SYSCON->OSTR=((SYSCON->OSTR & 0xff00ffff) | 0x00ff0000);
        SYSCON->GCER = ESOSC;
        //wait for EMOSC to stable
        while(!(csp_get_ckst(SYSCON)& ESOSC));
        return CSI_OK;
}
```

## 优化方式

```C++

        while(!(csp_get_ckst(SYSCON)& ESOSC));
        return CSI_OK;
}
```

## 测量方式

在等待时钟稳定信号的前后利用GPIO口翻转来测量消耗时间。
