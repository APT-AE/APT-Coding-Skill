# 测量同一个外部管脚上脉宽和周期的方法

# 方法（列出目标芯片支持的方式，请客户选择。）

## 方法一

exi边沿中断产生事件，触发捕获，在捕获中断里切换exi中断边沿触发方式，流程如下：

*exi配置为上升沿中断 \-\> 触发捕获 \-\> 修改exi配置为下降沿中断 \-\> 触发捕获 \-\> 修改exi配置为上升沿中断。。。*

这种方式非常消耗软件执行时间，主要包括：

- 从exi触发中断到gpta收到触发信号的时间

- gpta进中断的时间

- 中断代码的执行时间

- 中断代码的编写风格（直接操作寄存器还是调用api接口）

- 代码的优化等级

等等

所以，使用这种方式对捕获输入波形的频率和占空比都有要求，实测最高可以捕获到200KHz的波形，测试代码如下：

```C
**interrupt.c**
       if((GPTA0->MISR&GPT_CAP_LD0)==GPT_CAP_LD0)                //Capture Load to CMPA interrupt
        {
                GPTA0->ICR = 0x10;//GPT_CAP_LD0;        
                SYSCON->EXIRT |= EXI_PIN0;
                SYSCON->EXIFT &=~EXI_PIN0;
        }
        if((GPTA0->MISR&GPT_CAP_LD2)==GPT_CAP_LD2)                //Capture Load to CMPB interrupt
        {
                capflag = 1;
                GPTA0->ICR = 0x40;//GPT_CAP_LD1;
                SYSCON->EXIRT |= EXI_PIN0;
                SYSCON->EXIFT &= ~EXI_PIN0;//
        }
        
**main.c**
      while(1)
        {
                SYSCON_IWDCNT_Reload();      
                if(capflag)
                {
                        capflag=0;
                        UARTTxByte(UART0,(GPTA0->CMPA) >> 8);
                        UARTTxByte(UART0,(GPTA0->CMPA) & 0xff);
                        UARTTxByte(UART0,(GPTA0->CMPB) >> 8);
                        UARTTxByte(UART0,(GPTA0->CMPB) & 0xff);
                }
        }  
```



## 方法二

同一个exi管脚使用两个组（普通组+扩展组），分别对应上升沿事件和下降沿事件，通过ETCB同时触发捕获。
普通组: EXI GROUP0~15; 扩展组：EXI GROUP16-19。
比如 PA1下降沿使用EXI GROUP1(普通组)，PA1上升沿事件使用EXI GROUP16(扩展组)

这里需要注意
1、普通组和 扩展组都不是随便选的，要参考GPIO_IGRPL/GPIO_IGRPH/GPIO_IGREX寄存器的内容。
2、触发同一个目标时，要使用etcb的多对一通道，不能使用一对一通道（否则会丢弃其中一个通道的触发）。

由于没有软件来回切换的时间开销，全部由硬件直接触发完成，所以该方法可以极大提高捕获精度，实测可以捕获到8MHz的波形。

## 方法三
仅适用于APT32F173X及以后GPT/EPT版本。

APT32F173之前的芯片，无论EPT还是GPTx，捕获功能都无法区分上升沿或者下降沿事件。
在APT32F173的实现中，将之前的实现方法定义为合并捕获模式，同时增加了分开捕获模式：不同的边沿事件可以触发计数值load到不同的捕获寄存器。具体来说，SYNCIN2事件发生时，计数值load到CMPA；SYNCIN3事件发生时，计数值load到CMPB。结合ldrst操作，我们可以实现对输入波形高电平脉宽、低电平脉宽、周期长度的测量。
寄存器配置实现GPTx捕获，需要对以下模块进行配置：GPIO配置、触发配置、GPTx配置和ECTB配置。
- GPIO配置：同一个IO口同时产生上升沿和下降沿触发事件，需要用到IO口的外部扩展功能。在GPIO_IGREX寄存器中配置
- 触发配置：普通IO口可使用TRGSEL0~TRGSEL3作为触发源。外部扩展口，有单独的触发通道选择，SYSCON_EVTRG寄存器中配置，外部扩展可选择TRGSEL4或TRGSEL5作为触发源。
- GPTx配置：GPTx捕获，除了一些常规配置外，还需要注意以下配置：GPTx_CR(WAVE=0)寄存器，CMPMD_SEL控制位，配置为1，为分开捕获模式。
- ETCB配置：直接使用两个一对一的触发即可。
- 测量输入高电平脉宽和周期：配置：将IO上升沿事件通过ETCB做为SYNCIN2的事件源；其下降沿事件做为SYNCIN3的事件源；使能CMPA ldrst。 
- 结果：CMPB中读到的值就是该IO高电平脉宽，CMPA中读到的值就是该IO翻转的周期时间。
