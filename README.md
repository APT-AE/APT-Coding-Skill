# APT Coding Skill —— 爱普特芯片开发技能包

`v0.2.0`

这是一个"技能包"。装上它之后，AI 会成为你的爱普特芯片开发搭档——不管你是在把旧项目迁过来、从零开始新项目、还是排查现有代码的问题，AI 都会引导你一步步完成，帮你编译、带你上板验证。

> ⚠️ **前提：你用的 AI 工具必须能操作你电脑上的文件夹和文件**（自动读源码、改代码、命令行编译）。
> 像 Claude Code、CodeBuddy、Cursor 这类是可以的；**网页版 AI（浏览器里打开的那种）不行**——它碰不到你的电脑。

支持多种情况：
- case1：别家芯片（8051 / ARM / RISC-V / PIC 等任意架构）→ 换成爱普特（APT）
- case2：爱普特老型号 → 换成新型号
- case3：全新项目，从零开始用爱普特做
- case4：正在开发的爱普特项目，遇到问题希望ai协助诊断

**本技能包用的是通用的 `SKILL.md` 标准，支持所有主流的 AI 编程工具。**

---

## 安装

1. 下载本仓库的压缩包，**解压**得到文件夹 `apt-coding`（里面有 `SKILL.md` 和 `references`）。
2. 打开你的 AI 编程工具，告诉它：
   > 把这个 skill 安装上：[解压后的 apt-coding 文件夹路径]

   AI 会自己识别 `SKILL.md` 并放到正确的位置。

---

## 怎么用

**强烈建议每次都显式指定 skill，确保 AI 完整加载本技能包并按流程执行：**

> `/apt-coding` 

AI 会一步步引导你完成。

> ⚠️ 如果只是说"帮我改一下这个项目"而不指定 skill，AI 可能只把 skill 当参考资料翻翻，**不会严格按流程带你分步验证**。开头加 `/apt-coding` 就一定能完整激活。

**过程中你要做的事**：AI 改代码、帮你编译；轮到验证时，它会告诉你"把程序烧进板子，看某个灯亮不亮 / 拿表测某个脚"，你照做、把结果告诉它，它再继续。**跟着做、如实反馈给AI工具就行。**

> ⚠️ **AI 也会犯错。** 如果它给你的验证指引不合理——**请及时指出并纠正它**

---

## 动手前请准备好

- **CDK 开发环境，包括调试器**（编译下载调试用）
- **源工程代码（仅case1/2需要）**
- **目标APT芯片对应的demo工程代码**
- 一块 **目标芯片的开发板 + 烧录器**（迁移过程中要一个模块一个模块地烧进去验证）

没有板子也能改代码、能编译，但"验证对不对"这一步必须上板才能做。

---

## 遇到问题

直接在对话里把现象告诉 AI（比如"编译报了这个错""烧进去灯不亮"），它会帮你查。
