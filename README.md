# APT Coding Skill —— 爱普特芯片迁移助手

`v0.1.0`

这是一个"技能包"。装上它之后，AI 会**手把手带你**把旧的单片机项目改到 APT（爱普特）芯片上，每一步都帮你编译、教你上板验证，确认好了才走下一步。

> ⚠️ **前提：你用的 AI 工具必须能操作你电脑上的文件夹和文件**（自动读源码、改代码、命令行编译）。
> 像 Claude Code、CodeBuddy、Cursor 这类是可以的；**网页版 AI（浏览器里打开的那种）不行**——它碰不到你的电脑。

支持多种情况：
- 别家芯片（8051 / ARM / RISC-V / PIC 等任意架构）→ 换成爱普特（APT）
- 爱普特老型号 → 换成新型号
- 全新项目，从零开始用爱普特做
- 正在开发的爱普特项目，遇到问题希望ai协助诊断

**本技能包用的是通用的 `SKILL.md` 标准，支持所有主流的 AI 编程工具。**

---

## 安装

1. 下载本仓库的压缩包，**解压**得到文件夹 `apt-coding`（里面有 `SKILL.md` 和 `references`）。
2. 打开你的 AI 编程工具，告诉它：
   > 把这个 skill 安装上：[解压后的 apt-coding 文件夹路径]

   AI 会自己识别 `SKILL.md` 并放到正确的位置。**你怎么方便怎么来，不需要手动去记不同工具的目录。**

---

## 怎么用

用大白话向你的 AI 工具提出需求就行。比如：

> 我要把这个xxx项目从旧芯片改到 APT32F104，旧代码在xxx文件夹，APT 的示例工程在xxx文件夹。

AI 会自动加载这个技能，先问你几个问题，然后一步一步带你做。

**过程中你要做的事**：AI 改代码、帮你编译；轮到验证时，它会告诉你"把程序烧进板子，看某个灯亮不亮 / 拿表测某个脚"，你照做、把结果告诉它，它再继续。**你不用懂 AI，也不用会写代码，跟着做、如实反馈就行。**

---

## 动手前请准备好

- 目标 APT 芯片的 **CDK 开发环境**（编译要用）
- 一块 **目标芯片的开发板 + 烧录器**（迁移过程中要一个模块一个模块地烧进去验证）

没有板子也能改代码、能编译，但"验证对不对"这一步必须上板才能做。

---

## 遇到问题

直接在对话里把现象告诉 AI（比如"编译报了这个错""烧进去灯不亮"），它会帮你查。
